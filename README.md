# Smart Hospital Management System

A full-stack Smart Hospital Management System built using React, Tailwind CSS, and Supabase.

## Features

- Add Patients
- View Patients
- Delete Patients
- Cloud Database Integration
- Responsive UI
- Full CRUD Operations
- Modern Dashboard Design

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### Backend / Database
- Supabase
- PostgreSQL

## Project Structure

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_LINK
```

Go to project folder:

```bash
cd hospital-management
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
